
# 🛒 React Cart App

Este proyecto es un carrito de compras sencillo desarrollado con React. Fue creado como parte del curso "Aprende React desde cero" de Udemy, impartido por Juan Pablo De la Torre Valdez, y **personalizado por mí** con el objetivo de afianzar los conocimientos adquiridos y mejorar la experiencia de usuario.

El proyecto permite agregar, eliminar y gestionar productos de forma intuitiva, y es ideal como base para construir aplicaciones más complejas. Durante el desarrollo, implementé mejoras visuales y estructurales para adaptarlo a un entorno más profesional y responsivo.

## ✨ Personalizaciones realizadas

- Aplicación de estilos personalizados para mejorar la experiencia visual.
- Responsive completo utilizando Bootstrap y estilos propios.

## 🚀 Tecnologías

- React
- JavaScript
- Bootstrap 5
- CSS
- Vite

## 🛠 Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/react-cart-app.git
   ```

2. Navega a la carpeta del proyecto:
   ```bash
   cd react-cart-app
   ```

3. Instala las dependencias:
   ```bash
   npm install
   ```

4. Inicia la aplicación:
   ```bash
   npm run dev
   ```

## 🌐 Uso

Abre tu navegador y visita la ruta indicada por el servidor (por defecto `http://localhost:3000`).
